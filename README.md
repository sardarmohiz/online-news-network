# Online News Network V2
Includes public homepage and Supabase Auth admin dashboard.

1. Run `admin_policies.sql` in Supabase SQL Editor.
2. Open `admin.html`, login with the Supabase user you created.
3. Add news. Published articles appear on `index.html`.
4. Disable public sign-ups in Supabase Auth after creating your admin.

The browser uses only the Supabase publishable key. Never put a service-role/secret key in frontend code.
